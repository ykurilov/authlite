# Data Model: AuthLite v1

Таблицы создаёт и обновляет Better Auth (миграции при первом обращении). AuthLite своих таблиц не добавляет.

| Сущность спеки | Таблица | Ключевые поля | Правила |
|---|---|---|---|
| Пользователь | `user` | `id`, `email` (уникальный), `name`, `emailVerified`, `createdAt`, `updatedAt` | email обрезан и в нижнем регистре; `name` — пустая строка, если не задано |
| Пароль пользователя | `account` (`providerId = "credential"`) | `userId`, `password` (хэш scrypt) | длина пароля 8–128; хранится только хэш |
| Сессия | `session` | `id`, `token`, `userId`, `expiresAt`, `ipAddress`, `userAgent` | срок 30 дней, продление раз в сутки при активности; удаляется при выходе и сбросе пароля |
| Ссылка сброса | `verification` (`identifier = "reset-password:<token>"`) | `value = userId`, `expiresAt` | срок 1 час; удаляется после использования; при новой ссылке прежние того же пользователя удаляются |

## Переходы состояний

- Сессия: создана (регистрация/вход) → продлена (активность) → закрыта (выход, сброс, истёк срок).
- Ссылка сброса: создана → использована (удалена) | заменена новой (удалена) | истекла.

## Данные в памяти (не в базе)

- Счётчики частоты Better Auth (по адресу подключения и пути).
- Счётчик запросов сброса по email: 3 за 10 минут. Сбрасывается при перезапуске (допущение спеки).

## Публичная форма пользователя

`AuthLiteUser = { id: string; email: string; name: string | null }`
